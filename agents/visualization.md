### Phase 1: 图表类型选择

根据数据特征和展示目的选择图表类型：

| 数据特征 | 推荐图表 | 适用场景 |
|---------|---------|---------|
| 趋势（时间序列） | 折线图 | 模型收敛曲线、时间序列预测对比 |
| 分布 | 直方图/KDE/箱线图 | 数据分布、误差分布 |
| 类别对比 | 柱状图（带误差线） | 不同模型/方案性能对比 |
| 组成比例 | 堆叠柱状图（非饼图） | 资源分配、成分占比 |
| 相关性 | 散点图/热力图 | 变量相关性、特征重要性 |
| 空间分布 | 等值区域图/点地图 | 地理数据（如有） |
| 算法流程 | 流程图/框图 | 模型结构、求解步骤 |
| 多维对比 | 雷达图 | 多指标综合评价 |

**决策树**：
```
你的数据是？
├── 趋势（时间序列）
│   ├── 单一序列 → 折线图
│   └── 多序列对比 → 多线折线图
├── 分布
│   ├── 单变量连续 → 直方图 / KDE
│   ├── 多组对比 → 箱线图 / 小提琴图
│   └── 双变量 → 散点图 + 边际分布
├── 比较
│   ├── 组间数值 → 柱状图（带误差线）
│   └── 排名 → 水平柱状图
├── 关系
│   ├── 两变量 → 散点图 + 回归线
│   └── 多变量 → 相关性热力图
├── 组成
│   ├── 静态比例 → 堆叠柱状图
│   └── 随时间变化 → 堆叠面积图
└── 流程
    └── 算法步骤 → 流程图/框图
```

### Phase 2.5: 图-文-数据三方一致性自检（🔴 每图必做）

图必须**严格由算法实际运行输出完整记录绘制**：读取输出文件全量行（如 PSO K=150 → 150 个点），禁止估算/手写/仅取头部片段冒充完整轨迹，禁止先画图再倒推数据。绘制后逐项自检并记录证据到 `figure-list.md` 与 scope evidence：

| 检查项 | 判定 |
|---|---|
| 坐标轴范围 = 正文/数据声称范围 | 正文称 K=150 → 横轴 0~150；只展示前 10 代则标题/题注必须标注"前 N 代/局部"并删除与完整长度冲突的表述；否则自检 FAIL |
| 关键事件标记存在且位置正确 | 正文声称重启点 k=41、k=81 → 图中须有对应标记且落位正确；收敛阈值/切换点同理；否则 FAIL |
| 曲线形态符合算法预期 | 收敛曲线应随迭代下降/按算法定义演化；平直、贴 0、无变化须核对是否只含局部片段或读错数据；否则 FAIL |
| 图例-曲线-正文一致性 | 图例项数 = 曲线数；图例名与正文术语一致；无悬空图例 |
| 点/行数与输出文件一致 | 150 行 ↔ 150 点；抽样数值与输出文件逐行一致 |

自检未过 → 先用实际输出重绘（补齐范围/标记/数据源），再进入 Phase 3/4；不得把片段图直接入库。确需展示局部时改题为 "…(前 N 代/局部)" 并同步删除正文与完整长度冲突的描述。

### Phase 3: 图表标注规范

### 常见陷阱（两模式共用，合并去重版）

| 陷阱 | 问题 | 解决方案 |
|:----|:-----|:---------|
| 饼图 | 难以比较面积 | 用柱状图或堆叠柱状图代替 |
| 3D 图表 | 透视变形数据 | 默认只用 2D（理工科三维曲面等例外需注明视角与数值） |
| 坐标轴非 0 起始 | 夸大差异 | 条形图必须从 0 开始 |
| 过度颜色 | 分散注意力 | 最多 6-8 种颜色 |
| 数据-墨比低 | 装饰性元素过多 | 简化设计，突出数据 |
| 中文乱码 | matplotlib 默认不支持中文 | 设置中文字体 |
| 图例遮挡数据 | 数据点被覆盖 | 调整图例位置（upper right/outer） |
| 分辨率不足 | 印刷模糊 | dpi≥300 |

### 引用规范（**适用于所有文档领域**：Markdown、LaTeX、DOCX、HTML）

在引用图表时，必须使用**绝对引用**，禁止相对引用。原因：相对引用（"如下图""上表"）在文档重排版、翻译、跨格式转换时会失效——图表位置漂移后引用断裂。

#### 绝对引用 vs 相对引用

| 引用类型 | 示例 | 是否允许 |
|:---------|:----|:--------:|
| 绝对引用（图表编号） | `详见图1` / `如表2所示` / `图3 展示了...` | ✅ |
| 相对引用（位置描述） | `如下图` / `上表` / `下图显示` / `如图所示` | ❌ |
| 占位符引用 | `见图` / `见表` | ❌ |
