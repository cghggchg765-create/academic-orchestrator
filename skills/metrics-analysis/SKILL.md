# 指标分析

## 触发条件

当用户提到以下任何一项时加载此 Skill：
- "分析指标"、"性能对比报告"、"统计比较"
- "CPU 使用率"、"内存消耗"、"响应时间"、"吞吐量"、"延迟"
- "A/B 测试结果"、"实验组 vs 对照组"
- "版本 A 和版本 B 的性能对比"
- "运行时数据"、"监控数据"、"性能报表"

## 分析流程

### 一、数据理解（3 步）

1. **识别指标类型**：连续值（延迟/CPU）还是离散值（错误计数）？
2. **确认对比维度**：时间维度（前后对比）还是组间维度（A vs B）？
3. **检查数据质量**：样本量是否充足（每组 ≥ 30）？有无异常值？

### 二、统计方法选择

| 场景 | 方法 | 适用条件 |
|------|------|----------|
| 两组均值比较 | 独立样本 t 检验 / Welch t 检验 | 数据近似正态，方差不齐用 Welch |
| 多组均值比较 | 单因素 ANOVA + 事后检验 | 3 组及以上 |
| 非正态分布比较 | Mann-Whitney U 检验 | 数据明显偏态或有异常值 |
| 比例/率比较 | 卡方检验 / Fisher 精确检验 | 离散计数数据 |
| 相关性分析 | Pearson / Spearman 相关系数 | 两连续变量的关系强度 |
| 趋势检测 | 线性回归 / Mann-Kendall 检验 | 时间序列趋势 |

## 边界

- 统计方法选择必须基于数据特征，不能随意套用
- 当样本量 < 30 时应明确标注"样本量不足，统计检验效力有限"
- 分析结果不替代因果推断——相关性 ≠ 因果性
- 对涉及金钱/安全的决策，建议用户结合业务上下文综合判断
