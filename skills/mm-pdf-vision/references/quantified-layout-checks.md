# 排版量化核查（Quantified Layout Checks）

逐页读图能发现"这里空得厉害""图和文字对不上"，但**判断容易漏、修改后无法比较、也无法证明改好了**。
把每一项转成可测指标后，一次跑完全篇即可给出页码 + 数值，且修改前后可对照。

本文件是 `mm-pdf-vision` 的量化补充；脚本在 `scripts/`。

---

## 1. 六项指标

### 1.0 依赖与调用签名（先看这里）

| 脚本 | 必填依赖 | 调用签名 |
|------|---------|---------|
| `check_interruptions.py` | PyMuPDF | `<pdf> [统计页数]` —— **传 PDF 路径，不需要预先渲染** |
| `audit_float_citation.py` | PyMuPDF | `<pdf>`（同目录需有同名 `.aux`） |
| `measure_drift.py` | PyMuPDF | `<pdf>`（同目录需有同名 `.aux`） |
| `list_float_pages.py` | 无 | `<aux 路径>` |
| `measure_whitespace.py` | 无（读 PGM） | `<pgm-glob> <dpi>` —— ① 的备选，仅在装不上 PyMuPDF 时用 |
| `measure_figures.py` | PIL（有 struct 回退） | 无参数；⚠️ 脚本内 `FIGDIR` 与图列表为项目专属，复用前先改 |

依赖预检：`python -c "import fitz, PIL"`；缺失则 `pip install pymupdf pillow`，或改用已装好依赖的解释器（**项目 venv 常未安装 PyMuPDF，报"需要 PyMuPDF"就是解释器选错了**）。脚本已内置该检查，缺依赖会打印安装提示并非零退出，不抛裸 traceback。

### 1.1 指标表

| # | 指标 | 定义 | 脚本 | 判据 |
|:-:|------|------|------|------|
| 1 | **页底留白** | 该页最后一块正文的底边到版心下沿的距离（pt） | `check_interruptions.py` | 单页 >120pt 需处理；平均值用于追踪改善 |
| 2 | **段落被图表截断** | 某页以图表开头，且上一页最后一行不是句末标点 | `check_interruptions.py` | 必须为 **0**（最伤阅读体验） |
| 3 | **图表先于首次引用出现** | 图题/表题位置早于最早的 `\ref` 链接位置 | `audit_float_citation.py` | 必须为 **0**；"图前无引导句"同样计入 |
| 4 | **图表与引用的页距** | 引用所在页与图表所在页之差 | `measure_drift.py` | 同页优先；=1 相邻可接受；**≥2 视为漂移** |
| 5 | **表内实际渲染字号** | 从 PDF 抽取文本 span 的 `size`，按页统计 | 见 §4 片段 | 全篇表格统一（实测可发现 `\resizebox` 造成的 6.5pt vs 9.0pt） |
| 6 | **图片渲染高宽** | 从图源读 MediaBox（PDF）或像素（位图） | `measure_figures.py` | 数据图统一宽度；宽高比 >0.6 的结构图按**高度封顶**，否则会占据半页 |

渲染彩色页供**人看**、灰度页只供**量测**：
`pdftoppm -png -r 150 main.pdf out`（彩色，给人看）／`pdftoppm -gray -r 72 main.pdf gray`（灰度，给 `measure_whitespace.py`）。
⚠️ **不要把灰度图发给用户或用来判断版面观感**——曾发生过用户看到测量用的灰度渲染图后，误以为"PDF 变成黑白了"。给人看的图一律彩色。

> 注意：`check_interruptions.py` 直接读 PDF，**不需要**先渲染。

## 2. 三项权衡（最重要的经验）

**留白 / 段落截断 / 图文同页 三者不能同时最优。** 必须明确优先级，否则会在三者之间来回改、每轮都修好一个坏掉另一个。

| 方案 | 段落截断 | 页底留白 | 图文同页 | 机理 |
|------|:-------:|:-------:|:-------:|------|
| `[H]` 强制就位 | **永不截断** | 有（图表前那页留空） | 通常同页 | 分页只发生在图表声明处，而图表在源码里都放在完整段落之后 |
| `[htbp]` 浮动 | 会截断 | 几乎没有 | 常相邻 | 图表被推到次页页顶后，**后面那段文字被拉上来填满上一页**，段落被切成两半 |
| `\needspace{N}` | 不截断 | 增加一段高度的留白 | 强制同页 | 引用段整段移到次页，与图同页 |

**推荐优先级**：① 段落不被截断 → ② 压留白 → ③ 对用户点名的少数图加同页约束。
加同页约束时**必须逐例核对留白代价**：本技能在实践中遇到过阈值取 15–17 `\baselineskip` 导致第10页、第18页分别留下 520pt、628pt（近乎整页空白），最终只保留了个别确有必要的位置。

## 3. 常用修复手法与代价

| 现象 | 手法 | 代价 / 注意 |
|------|------|------|
| 图过高占据半页 | 按**高度封顶**缩放（宽高比 >0.6 的结构图），而非统一宽度 | 结构图宽度会小于数据图，需要向用户说明这是唯一可行解 |
| 图表前页留白大 | 缩小该浮动体使其就地放下 | 会破坏"所有图一样大"的统一性 |
| 引用在页底、图在次页 | `\needspace{N\baselineskip}` 前置于引用段 | 引用页出现等于该段高度的留白；阈值宁可略小 |
| 页面大片空白但不想动图 | **在空白页所在节补写分析文字** | 最干净的解法：补的内容必须来自论文已有数据，不得引入未验证数值。**👉 必须先取得用户同意（见 §3.1）** |
| 表格超高放不下 | 压缩 `\arraystretch`（只改行距不改字号）、`\tabcolsep`；仍不行则**转置或减列** | 切勿用 `\resizebox` 缩放——实际字号会变成不可预测的小值 |
| 表宽超出版心 | 转置（行↔列）、缩短表头、减少小数位 | 转置常同时改善可读性 |
| 首页标题上方多出约 40pt 空隙 | 检查模板 cls 的摘要环境是否用 `\newpage\null` 结尾，改为 `\clearpage` | `\null` 在页顶插入空盒，使标题的前置间距不被"页顶胶水丢弃"规则吃掉 |
| 引用是行内 `[1]` 而要求上标 | 用模板自带的 `\upcite`（cumcmthesis 在 cls 中已定义），把 `\cite{` 全量替换为 `\upcite{` | 替换后需确认文献仍全部被引用，未出现"列而不引" |

### 3.1 补写正文内容——需要用户同意的兜底手段

当局部的排版调整（缩图、压行距、转置表格、调浮动位置）**都无法消除某页的大片空白**时，可以考虑在该页所在的小节补写分析文字。这是所有手段里最"重"的一种，因为它改的是**论文内容**而不是版面，所以设一道门禁：

**执行前提（缺一不可）**

1. **已穷尽排版手段**：先试过与该页相关的图表缩放/重排/表格紧凑化/浮动位置调整，并记录每项尝试的留白变化，确认确实压不下去。空白常来自"该页要放的表/图过高放不下"（本技能实测：表 400pt 而该页只剩 287pt），这类硬约束缩图往往要缩到不可读。
2. **先取得用户同意**：向用户说明①哪一页、②空白多少、③排版手段已试过哪些、④准备补在哪一节、补什么内容，得到明确同意后再动手。**不要自行决定增补正文**——用户可能宁可直接定稿，或希望换一种处理方式。
3. **内容有据**：补写的分析必须**只用论文自身已有的数据**（正文数字、表里的分项、图中的量），并逐项核对来源可追溯。不得为了让页面好看而引入未经验证的数值、编造对照或臆测因果。
4. **补完复核**：重编译后确认该页留白下降、且没有把问题挪到相邻页；同时复跑"段落是否被截断""图表是否先引用后出现"两项，确认增补段落没有破坏原有的图表对应关系。

**向用户请示时的一句话模板**：

> 第 N 页底部有 X pt 空白（约占该页 Y%），成因是「表Z 高 W pt 而该页仅剩 V pt，缩到能放下会让字号不可读」。排版手段已无解，是否允许我在 §K 补一段约 L 行的分析（内容仅使用论文已有的 <数据来源>）来填补？

## 4. 无脚本时的临时量测片段

表内实际字号（可发现 `\resizebox`/`\scriptsize` 造成的不一致）：

```python
import fitz, collections
doc = fitz.open("main.pdf")
for pno in range(doc.page_count):
    c = collections.Counter()
    for b in doc[pno].get_text("dict")["blocks"]:
        if b["type"] != 0: continue
        for l in b["lines"]:
            for s in l["spans"]:
                if s["text"].strip(): c[round(s["size"], 1)] += len(s["text"])
    if 9.0 in c and c[9.0] > 200:      # 表格正文通常集中在 9.0pt
        print(f"p{pno+1}: {dict(sorted(c.items()))}")
```

页面顶部空隙（可发现标题上方异常空白）：取该页第一个文本块的 `y0` 与版心上沿之差，正常应 ≈0。

## 5. 陷阱清单

1. **修改后必须重编译再核查**：源码改了而 PDF 未重编译，核查的是旧版面；`main.aux` 与 PDF 不同源会让引用审计读出错误页码（表现为同一份 PDF 两次审计结果不同）。
2. **Windows 下 `main.pdf` 可能被占用**（阅读器/预览/钩子进程），`xdvipdfmx` 报 `Unable to open`；用 `-jobname=build` 备用名编译，再把 `build.pdf` 复制为正式产物，最后用正式名重编一次使 `main.aux` 与 PDF 同源。
3. **并行写入风险**：同一工作区可能另有会话在编辑同一批 `.tex`。发现"自己没改却变了"时，比对 mtime 与编译产物，不要只信最后一次编辑；复核时以**编译结果**为准。
4. **`\needspace` 阈值过大会整页空白**（见 §2）。
5. **`\FloatBarrier` 只约束浮动体，不约束文字拉取**；它对 `[H]` 布局基本是空操作。
6. **图题位置用链接目标 y 判断不可靠**（hyperref 的目标 y 可能回落到页底）。判断"图先于引用"应**从 PDF 内容里定位题注块**（以"图 N"/"表 N"开头的文本块）作为图的纵向位置。
7. **数字类问题先查口径再改论文**：论文数值与随附脚本复算不一致时，常见成因是评价窗口不同（如 334 天 vs 364 天）、池化方式不同、或脚本里的切片错位；应先穷举候选口径求出可复现的那一个，而不是直接把论文改成脚本输出。本次实践中"不可复现"的指标最终被证明是**脚本对齐缺陷**，论文原值正确。
8. **图片尺寸统一 ≠ 全部同宽**：宽高比差异很大时（流程图 1.0+ vs 数据图 0.45），"同宽"会使流程图高度翻倍。正确目标是**视觉块面相近**：数据图统一宽度 + 结构图高度封顶。

## 6. 标准工作流

```
① 重编译，确认产物与源码同源（记录页数、CreationDate）
② 跑 6 项量化指标，得到基线：留白分布 / 截断数 / 先引用后出现数 / 页距分布 / 表字号 / 图尺寸
③ 渲染全页图片（彩色）逐页视觉核查，对照量化结果定位到具体页与具体段落
④ 定优先级：截断 → 留白 → 个别同页约束
⑤ 改排版（尺寸、[H]、屏障、needspace、cls）
⑥ 重编译 → 复跑量化指标 → 与基线对比，确认没有把问题挪到别处
⑦ 排版手段都无法消除的空白：先向用户请示，**获同意后**才在该节补写分析文字（只用论文已有数据）
⑧ 输出验收表：改前/改后 每项指标的数值对照
```

**汇报口径**：给用户的结论要带**页码 + 数值 + 改前后对照**，而不是"我看过了，还行"。例如"空白 >120pt 的页：3 页 → 0 页；平均留白 44.7pt → 27.8pt"。
