# MM LaTeX Writing — 国赛论文写作规范

## 🔴 加载资格与委托守则（必须读）

本技能是 **写作（writing）子代理** 的专项规范，**仅供 `writing` 子代理加载执行**。

- 若你是主对话主 agent：收到论文写作 / 修改 / 润色 / 审阅修改 / 格式检查请求时，**不得直接加载本技能内联编辑论文**——必须先通过 Agent 工具派发 `subagent_type=writing` 子代理（把用户问题清单 + 文件路径传入其 prompt），由子代理加载本技能执行。
- 主对话直接加载本技能改 .tex = 违规内联代做（破坏执行-审阅分离，与编排铁律冲突）。
- writing 子代理完成修改后必须走验证闭环：输出 `[REVIEW-REQUEST] 节点=N7` → reviewer 审阅 → latex_linter 质检 + 编译验证 → 通过后才交付。

## 🔴 分片写作与阶段顺序（N7 scope 模式）

- 论文任务先由 orchestrator 生成 `state/reviews/N7/round_<n>/<scope_id>/` 工作区和 bounded `input_manifest.json`；writing 只读取当前 scope 的目标章节/小节、相邻上下文与证据指针，禁止把整篇论文一次性作为输入。
- 首轮 `reviewer` 内容审阅与 `latex_linter` 格式审阅均为只读，可并行；报告分别写入 `content_review/` 与 `format_review/`，缺报告、空报告或无 evidence 不得汇总为 PASS。
- 汇总后先由 writing 对内容问题**串行**修订，并由 reviewer 对每个 scope 反向复审；全部内容 scope PASS 前，禁止 typesetting 修改共享 `.tex`、preamble、交叉引用或图表题注。
- 内容全部通过后才进入 typesetting 排版修订；排版写入完成必须重新编译，再由 latex_linter 与 reviewer 反向复核，最后做全文 join review。单个 scope PASS 不等于 N7 父节点完成。
- 每个 scope 结果必须带 `scope_id`、`phase`、`target_ref`、`changed_files`、`checks`、`timestamps` 和 artifact 哈希；空返回统一标记 `EMPTY_RETURN`，只重试一次，仍失败即 `BLOCKED/ESCALATE`。

国赛(CUMCM)数学建模论文的结构规范、LaTeX 模板对接与排版标准。**产物落 `ReportPaper/LaTeX/`**（含 main/preamble/config/ref.bib/sections/），图片用相对路径引用 `../../ResultFigures/`（Windows 下不用软链接）。

## 国赛论文结构（10 节，节号 1-10）

| 序号 | 节标题 | 页数建议 | 内容要点 |
|:----:|-------|:--------:|---------|
| 1 | **摘要** | ≤1 页 | 问题、方法、模型、结果、关键词（每问 ≥1 个数字） |
| 2 | **问题重述** | 0.5-1 页 | 用自己的话重述题目，提炼核心问题 |
| 3 | **问题分析** | 1-2 页 | 逐题分析思路，整体建模框架 |
| 4 | **模型假设** | 0.5-1 页 | 假设列表，逐条说明合理性（依据 mm-self-review 维度一 1.1-1.6） |
| 5 | **符号说明** | 0.5 页 | 表格列出所有符号及含义 |
| 6 | **模型建立与求解** | 6-8 页 | 核心章节：模型推导（与 `ModelDocs/formula.md` 一致）、求解过程、结果 |
| 7 | **模型检验** | 1-2 页 | 灵敏度分析（`ModelDocs/sensitivity-analysis.md`）、交叉验证、误差分析 |
| 8 | **模型评价** | 0.5-1 页 | 优点、缺点、改进方向（🔴 连贯段落自评，禁"序号+单句"罗列） |
| 9 | **参考文献** | 0.5-1 页 | GB/T 7714 格式（**英文文献占比 ≥ 30%**） |
| 10 | **附录** | 页数不限 | 支撑材料文件列表 + 完整可运行源码（**必须**）、补充数据、详细推导 |

**CUMCM 2026 页面约束（以导出 PDF 为准）**：第 1 页承诺书、第 2 页编号专用页（均无页码）；第 3 页摘要页（摘要+关键词，≤1 页，页码从摘要页记 1）；第 4 页起为正文，**正文不超过 30 页**；正文结束后为附录，附录页数不限。正文页数只从 PDF 第 4 页数到正文结束，不能用 Word 页数替代；禁止目录。统一 profile：`shared/contracts/submission/cumcm_2026_format_profile.json`。

## 官方格式规范（CUMCM 2025/2026 修订稿，🔴 硬性）

| 项目 | 要求 |
|------|------|
| 纸张与边距 | A4 纸；四边距 ≥ 2.5cm（见下文 `\geometry` 设置）；**左侧装订**，装订侧留足空间 |
| 页面顺序 | PDF 第1页承诺书 → 第2页编号专用页 → 第3页摘要页 → 第4页起正文 → 正文后附录；**不要目录** |

| 附录 | 必须包含支撑材料文件列表 + 全部完整可运行源码；程序不能运行或结果与论文不符 → 可能取消评奖资格 |
| 匿名性 | 🔴 全文任何位置（页眉页脚、图表水印、附录、文件属性）不得出现身份/学校信息 |
| 文件大小 | 论文 PDF ≤20MB；支撑材料代码/数据压缩包 ≤20MB；两者是两个独立文件，不能混入 PDF |


## 每节写作要点

### 摘要（最重要）

结构模板（约 500-800 字）：

```
第一段：问题概述（1-2句）
  针对XX问题，本文建立了...

第二段：方法与模型（核心，3-5句）
  首先，针对子问题一，建立了XX模型...
  其次，针对子问题二，采用XX方法...
  最后，针对子问题三，设计了XX方案...

第三段：关键结果（2-3句）
  结果表明：...（给出核心数值结果）

第四段：模型特色/创新（1-2句）
  本文的创新点在于...

关键词：关键词1; 关键词2; 关键词3; 关键词4; 关键词5（3-5个）
```

**摘要四要素（🔴 评委初评仅 5-10 分钟，摘要决定第一印象）**：每个子问题都必须覆盖——
1. **解决了什么问题**：哪一问、输入数据、要求输出什么；
2. **用了什么模型与方法**：模型类型 + 求解算法，**点名不展开**（不写推导过程）；
3. **得到什么数值结果**：每问关键数字 + 单位；
4. **结果说明了什么**：一句话结论；若做了灵敏度分析，注明"结论在参数扰动下保持稳定"。

**摘要内容完整度（韩中庚《数学建模竞赛论文的写作方法》）**：每个问题都说清七要素——用什么方法、建什么模型、如何求解、主要结果、解决了什么、效果如何、特色创新点。

**摘要禁区（🔴）**：
- **不出现复杂公式和表格**（公式化摘要评委不看；公式图表一律放正文）；
- 篇幅 A4 大半页、≤ 1 页，高度浓缩，禁止把正文段落搬进摘要；
- 避免"形式化""公式化"表述（套话清单见 Anti-Patterns）。

**摘要检查清单：**
- [ ] 覆盖了所有子问题
- [ ] 每个子问题都有明确的方法和结果
- [ ] 核心数值结果已给出
- [ ] 字数在 500-800 字之间
- [ ] 关键词 3-5 个
- [ ] 每个子问题覆盖摘要四要素（问题/方法/数值结果/结论）
- [ ] 无复杂公式、无表格

### 问题重述

- 对赛题**正确解读后的重新表述**，非简单复制（复制题目原文 = 评阅印象差）
- **澄清题目中模糊的概念与条件**（如"尽可能多""单位面积成本"等未量化表述，给出合理界定与解释）
- 提炼核心问题（通常 2-3 个子问题）
- 明确边界条件和约束
- 与问题分析衔接：重述点明"要做什么"，分析说明"怎么做"

### 模型假设

每条假设格式：
```
假设1：[假设内容]
理由：[物理/逻辑依据]
影响：[对模型的简化作用]
```

**假设数量与内容控制（🔴 评审工具不得入正文）**：

- 假设总数控制在 **≤ 8 条**；只保留建模必需的假设——官方评阅标准"假设的合理性"要求**每条假设都能指出它简化了模型的哪一步**，写不出对应关系的假设在评委眼里只是凑数（删）；
- **禁止**在假设章节出现评审/分析工具类内容：假设影响矩阵、影响程度分级表（小/中/大）、评分表等——这些是团队内部评审工具，不是论文内容；若确有分析价值，移入附录；
- 每条假设与后续模型建立一一呼应（正文建模处可回指"由假设 3…"）；
- **假设有效性铁律（Acadwrite 评委视角）**：每条假设必须对应**一处具体模型简化**，且能在建模一节找到**生效位置**——自查时逐条追问"删掉这条假设，模型哪一步会变？"，答不出即删；
- **禁止万能假设**："数据真实可靠""不考虑其他因素""忽略随机误差"等放之四海皆准的假设等于没写，评委视为凑数。

### 符号说明

标准表格格式：

| 符号 | 含义 | 单位 | 类型 |
|------|------|------|------|
| $x_i$ | 第 $i$ 个决策变量 | - | 决策变量 |
| $c_j$ | 第 $j$ 项成本系数 | 元 | 参数 |
| $f(x)$ | 目标函数 | - | 函数 |

**符号表精简铁律（🔴 防"符号说明比正文还复杂"）**：

- 只列**正文实际出现且被引用的符号**；出现次数极少（≤2 次）且含义自明的符号不列入；
- **禁止**在符号表内写叙述性文字（如"本问特有符号总计 N 个，覆盖…"）——表内只放 符号/含义/单位/类型 四列；
- 分组 `\multicolumn` 标题 ≤ 3-4 组，组名简洁（基本参数/状态量/决策变量/输出量 等）；
- 全文符号总量建议 ≤ 25 个；同一含义不得重复列两个符号，同一符号不得给两个含义；
- 符号说明节页数 ≤ 0.5 页，超过则按出现频率裁剪。

### 模型建立与求解

- 每个模型先给出数学表述
- 再给出求解算法
- 最后给出结果
- 公式编号连续
- **符号首次出现时给出定义**（不依赖读者回头查符号表；格式："设 $x_i$ 为第 $i$ 个决策变量（单位：万元）"）；
- **图表必须被正文显式引用**：每个 figure/table 在正文中至少有一处"由图 N 可知…/见表 N…"式引导句，禁止只插入不引用（孤立图表 = 无效内容）；
- **公式连排必须有文字衔接**：两个编号公式之间必须有一段说明文字（"将式 (5) 代入式 (6) 可得…"），禁止公式一个接一个无过渡文字。

### 模型检验

必须包含：
- 灵敏度分析（关键参数变动）
- 误差分析（与真实值对比）
- 稳定性检验（多次运行）

**灵敏度分析硬性要求（🔴 禁止空口说稳定）**：
- 至少对一个关键参数做扰动（如 ±5%、±10% 或多组离散取值），**给出扰动后的数值结果**（表格或曲线），并逐条说明结论是否改变；
- 结论不变时写明"参数 $a$ 在 ±10% 扰动范围内最优方案不变"；结论改变时说明变化趋势与临界点；
- **禁止**只写"经检验模型稳定性良好"而无任何扰动数值（评委视为空话）。

### 模型评价（🔴 必须客观自评，与科技论文不同）

竞赛论文**要求作者必须客观评价自己论文的优缺点**（官方评阅要求；区别于科技论文"不允许自评"的惯例）：
- 优点：1-3 条，写模型/方法的真实可取之处（与实际问题贴合度、求解效率、可扩展性），**禁止自夸空话**（"本文模型具有重要的现实意义"）；
- 缺点：1-2 条，诚实指出局限（数据范围、假设边界、算法复杂度）并说明适用边界；
- 改进方向：2-3 条可落地方向（更换更优算法、引入更多数据、放宽某条假设后的处理方案）；
- 每条优缺点都能回指正文（如"缺点对应假设 4 的局限"），避免泛泛而谈；
- 🔴 **成文必须是连贯段落，禁止"序号+一句话"罗列**：每条优点/缺点/改进方向写成完整段落（论点 + 依据 + 对结果的影响，2-4 句），段落间自然衔接过渡。"1. 局部平面近似的局限：……"这种逐条单句列表 AI 味极重；确需并列仅限段内少量完整句，不得整节编号罗列。

## 数据来源标注规范（🔴 写作/图表/审阅统一口径）

论文写作必须先判定数据类别，再决定图表注释、正文说明、参考文献和支撑材料要求：

| 数据类别 | 论文标注 | 支撑材料/引用 |
|---|---|---|
| 赛题直接给出的原始数据 | 通常不在正文和图表重复写“数据来源”；不得伪称外部公开资料 | 按当年竞赛要求处理，不把赛题原始数据冒充文献或外部数据放入参考文献/附录 |
| 外部公开/文献/网页/数据库数据 | 图注/表注写明机构、数据集/报告、日期或访问时间；正文引用，文末 GB/T 7714 完整著录；禁止“来源于网络” | 原始数据集或可复现下载说明纳入支撑材料压缩包 |
| 代码仿真/模型输出数据 | 明确写“本文模型计算/仿真得到”，不得伪装成真实观测或公开数据 | 附录保留完整可运行代码、参数和随机种子；不作为外部文献引用 |
| 问卷/实地调研一手数据 | 写明调研时间、方式/地点和有效样本量 | 保留调查设计、匿名原始数据或可核验汇总及处理说明 |

🔴 内部文件路径（`Code/output/`、`ModelDocs/`、`*.txt`、`*.xlsx`、`*.log`）只能留在 scope evidence 和支撑材料清单，禁止出现在论文题注、表注、正文中；数据来源必须转换成学术可核验表述。

### 注释精简与去内务话术（🔴 表注/图注"少而精"）

- **同一来源只说明一次**：若整篇或整节数据同出一处（如全部来自本文模型仿真），在**首次涉及处用一句话统一说明**（或按官方规范在正文交代），后续同源图表**不再逐表/逐图重复标注**。反例（每表都写）："注：表内数值均由本文基于赛题参数仿真计算得到，完整代码与逐条明细见提交包独立附件；表内总长度、首条位置、边界阈值均来自代码输出并已按式(17)复核，完整逐条结果不在本文重复。" ——应压缩为首次一句话（如"表中数据由本文模型仿真计算得到"）或直接省略。
- **禁止内务/复现话术**：表注/图注中不得出现"完整代码见附件""逐条明细见独立附件""按式(x)复核""由同一输出复核""不在本文重复""详见提交包"等重复性说明；复现信息统一由附录的支撑材料列表承担，不在每张图表重复交代。
- **注释只写表格/图形本身未体现且读者必要的信息**：单位、缩写定义、显著性标记、个别口径说明；与图表信息重复的内容一律不写。全文表注/图注的条数应明显少于图表数（多数图表可无注或无"数据来源"字样）。
- **表内"每一行按该表实际需求组织"**：行数由表格承载的数据实体决定（如每条测线、每组阈值、每个方案），不许为了凑对齐硬补空行/虚行；不追求机械统一列数而填充无意义占位。
- **外部过程零进入**：迭代轮数、版本、修改前后对比、"与上一个版本相比"、内部工作量、代码调试、参数试凑等**外部/内部工作过程**一律不得进入论文正文、图表题注、表注和对比表；内部对比只留存在 `state/reports/`、`state/reviews/` 与 git 记录中，论文只呈现最终模型与结果。发现此类语言返回 writing 按"删除并改为最终结果表述"修订。

## LaTeX 模板对接说明

### 文档类设置

```latex
\documentclass[UTF8, a4paper, 12pt]{ctexart}

% 必要包
\usepackage{amsmath, amssymb, amsfonts}  % 数学公式
\usepackage{graphicx}                     % 图片
```

### 图片插入

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{../../ResultFigures/comparison/fig1_results_comparison.pdf}
  \caption{模型求解结果对比}
  \label{fig:result}
\end{figure}
```

**防漂移（图表不得插在文段中间）**：

- 一律使用浮动环境 `[htbp]`，**禁止 `[H]` 硬插**到段落中间把文字截断；
- 图表前后各保留一个空行（独立段落），`\end{figure}` 后不得直接接文字；
- 正文先用引导句引用（"如图 X 所示"），图表在引用处之后由 LaTeX 浮动到合适位置；
- 🔴 **图表不得漂移到其所属章节标题之前**：LaTeX 浮动可跨节上漂（典型事故："表1 符号说明表"漂到第 5 节"符号说明"标题之前、挂在上一节末尾，章节与表格顺序颠倒）；编译后逐页核对 PDF 顺序——每个图表必须位于【其所属章节标题之后 + 正文首次引用之后】两个约束同时满足；节内首表（如符号表）必要时在章节标题后加 `\FloatBarrier` 或将 table 环境源码下移到该节引导段之后；
- 🔴 **图表不得远离其首次引用所在文段**：编译后逐页核对，图表应落在其引导句（"如图 X 所示/见表 X"）所在页或相邻页；若图表被推离引用段两页以上（表格连续漂移、图后接表再接图等），在引用段后收紧浮动参数（`[htbp]` 调 `[ht]`、合并子图、压缩表宽）或在该节末尾加 `\FloatBarrier`；禁止图表与其引导文字跨多页失联；
- 编译后逐页检查：无段落被图表从中间截断、图表不早于首次引用、图表不早于所属章节标题、图表不与引导文段分离过远。

**子图合并（同类图合并为一个图）**：同一对比主题的多张图（多方案/多参数/多时段）合并为一个 figure 内的多个 subfigure：

```latex
\begin{figure}[htbp]
  \centering
  \begin{subfigure}{0.45\textwidth}
    \centering
    \includegraphics[width=\textwidth]{../../ResultFigures/curve/fig2a.png}
    \caption{方案 A 结果}\label{fig:cmp-a}
  \end{subfigure}
  \hfill
  \begin{subfigure}{0.45\textwidth}
    \centering
    \includegraphics[width=\textwidth]{../../ResultFigures/curve/fig2b.png}
    \caption{方案 B 结果}\label{fig:cmp-b}
  \end{subfigure}
  \caption{不同方案结果对比}\label{fig:cmp}
\end{figure}
```

- 子图宽度统一、尺寸一致；正文引用总图 `\ref{fig:cmp}`，指向子图用 `\ref{fig:cmp-a}`；
- 图注（总 caption）与子图标题字体由模板统一控制，正文不手工加粗/改字号。

**图片尺寸统一（🔴 防"图大小不一"）**：

- 同一章节（或同一对比组）的图片 `width` 取值统一（如全部 0.65\textwidth），禁止同章出现 0.7/0.65/0.5 混用；例外：整页大图/示意图可按内容调整并说明理由；
- 子图最小宽度 ≥ 0.4\textwidth（两子图并排时）；三子图及以上并排时每子图 ≥ 0.3\textwidth——**子图过小导致文字/曲线不可读时，宁可改上下排列也不缩小宽度**；
- 图题（caption）规范（🔴 简约直接，一行以内）：图题在图下方居中，格式"图N 对象+内容"（如"图3 覆盖宽度随距离变化"），建议 ≤20 字、排版最多一行；描述用词与正文一致；**禁止** caption 中出现 $\to$、公式推导、流程复述（"Q1 二维几何 → Q2 三维推广 → …"属图形内容解读，应移入正文）等非描述性内容；**禁止**图题内塞入数据来源、文件路径、绘制方法、附件指引（"数据源：Code/output/…、图示位置按代码输出绘制、完整表格见附件"一律移出图题）；
- **数据来源与补充说明**：放图下方的注释行（`\footnotesize`、**左对齐**、以"注："开头、一行简短）或正文叙述；🔴 不得并入图题、不得写成两端对齐的正文段落紧贴图题；图题与后续正文必须分段（空行），禁止图题后直接连排文字；图注与表注同受"注释精简与去内务话术"约束（同源一句话统一、禁"完整代码见附件/按式(x)复核/不在本文重复"类重复说明）；
- 图片插入后人工检查：放大到打印尺寸仍可读（坐标刻度、图例、标注字迹清晰）。

**图表命名与标题规范（🔴 防"标题乱起"）**：

- 表题在表**上方**居中，图题在图**下方**居中；全文一致；
- 标题格式统一为"图/表N + 空格 + 对象 + 内容/结论"（如"图2 不同测线方向的漏测面积对比"），禁止空泛标题（"结果图"、"数据表"）、禁止中文数字混用（图一/图1）；
- 同一图表标题中的术语、符号、单位与正文一致；标题内尽量不出现未定义缩写。

**图片质量规范（🔴 韩中庚《数学建模竞赛论文的写作方法》）**：

- **自明性**：图不与表/文字重复表达同一内容；独立可读（不回头读正文也能看懂图意）；
- 精心绘制、大小适中、线条均匀、**主辅线分明**（主线粗、辅助线/网格细）；
- **图中文字与符号植字大小介于 6 号至小 5 号之间**（打印到实际尺寸后仍清晰可读）；
- 坐标轴与标注**单位齐全**（如 x 轴标注"时间/h"而非只有数字）；
- 图中术语、符号、单位与正文**完全一致**（禁止图内与正文同一量使用不同写法）；
- 图号图题在图**下方居中**、**字号比正文小一号**；
- **先见文字后见图**：正文引导句在引用处先出现，图由 LaTeX 浮动到引用之后。

### 三线表

```latex
\begin{table}[htbp]
  \centering
  \caption{不同方案性能对比}
  \label{tab:compare}
  \begin{tabular}{lccc}
    \toprule
    方案 & 准确率 & 运行时间 & 成本 \\
    \midrule
    方案一 & 92.3\% & 15s & 100元 \\
    方案二 & 89.7\% & 8s  & 80元  \\
    方案三 & 95.1\% & 30s & 150元 \\
    \bottomrule
  \end{tabular}
  % 🔴 表注放 table 环境内、tabular 之后（随表浮动；推荐 threeparttable 的 tablenotes），
  % 左对齐 footnotesize、与表体留间距；"注"字不得进入 tabular 行内
  \vspace{4pt}
  {\footnotesize 注：准确率为 5 次重复实验均值；数据由本文模型计算得到。\par}
\end{table}
```

**表格尺寸与注释规范**：

- **宽度固定**：表格宽度 ≤ `\textwidth`；全文统一采用同一宽度策略（整表 = `\textwidth` 或统一比例），禁止同页两张表格宽度不一致；
- **字号统一**：全文表格字号在 `\small` 与 `\footnotesize` 中二选一，表头与表体一致，禁止混用；
- **列宽控制**：长文本列用 `p{\dimexpr0.2\textwidth-2\tabcolsep\relax}` 相对宽度自动换行，禁止随意 `cm` 组合导致列宽漂移；数值列右对齐；
- **三线表**：只用 `\toprule / \midrule / \bottomrule`，禁止竖线与全框线；
- **表注（🔴 随表浮动 + 一行简短 + 防吞字 + 防内部路径）**：写在 `table` 环境**内**、`\end{tabular}` 之后（推荐 `threeparttable` 的 `tablenotes`，需 `\usepackage{threeparttable}`；简化写法 `\vspace{4pt}{\footnotesize 注：…\par}`），**左对齐** `\footnotesize`、以"注："开头、与表体留 3-6pt 间距——保证注释随表格浮动不分离、不被视觉吞进表内，也避免写在 `\end{table}` 之后滞留源码位置变成"紧贴表格的正文"；"注"字严禁出现在 `tabular` 行内；🔴 注内容**一行简短**：数据来源只写"数据由本文模型计算得到 / 数据来源：文献[n] / <官方数据集名>"，**禁止罗列内部文件路径与文件名**（`Code/output/…`、`*.txt`、`*.xlsx`、`*.log`）及工程黑话（canonical/legacy/debug 等）；全文表注格式统一；
- **表格后衔接**：`\end{table}` 后必须空一行再写正文，禁止字段与表格同行；
- **表格之间不得连续排列**：两个表格（或表与图）之间必须有一段文字叙述该表结果的含义（先见文字后见表），禁止表-表/表-图无过渡紧贴；
- 长表格拆分为表1/表2 或使用 `longtable`，禁止表格跨页切断正文；
- **自明性**：表不与图/文字重复表达；项目栏标注齐全详尽不省略（列名必须完整，禁止"数据""结果"等无信息量列名）；
- **单位标注**：所有栏单位相同时，单位标在**表格右上角**（如"单位：元"），禁止每列重复写单位；各栏单位不同时，单位随列头标注；
- 表内术语、符号、单位与正文一致；表号表题在表**上方居中**；
- **先见文字后见表**：表前必须有 1-2 句文字引出该表内容。

### 参考文献格式（GB/T 7714）

```latex
\begin{thebibliography}{99}
  \bibitem{ref1} 作者. 标题[J]. 期刊名, 年, 卷(期): 页码.
  \bibitem{ref2} 作者. 书名[M]. 出版地: 出版社, 年.
  \bibitem{ref3} 作者. 论文标题[D]. 城市: 学校名, 年.
\end{thebibliography}
```

示例：
```latex
\bibitem{deng2002}
邓聚龙. 灰色系统理论教程[M]. 武汉: 华中科技大学出版社, 2002.

\bibitem{zhang2020}
张三, 李四. 基于遗传算法的车间调度优化[J]. 系统工程理论与实践, 2020, 40(3): 567-578.
```

**参考文献检查（🔴 一一对应）**：
- 信息完整：作者/题名/刊名/年卷期/页码缺一不可；网络来源必须给出可核验的 DOI 或 URL（含访问日期）；
- **正文引用处与文献表一一对应**：正文 `\cite` 的每个 key 必须在文献表存在，文献表每条必须被正文至少引用一次（未被引用的文献 = 凑数）；
- **禁止**用格式混乱、来源不明的链接充数（如只给一个裸 URL、无标题/作者/出处）。

## 编号规范汇总

| 对象 | 格式 | 示例 | LaTeX 命令 |
|------|------|------|-----------|
| 公式 | (1), (2), ... | 见公式 (3) | `\eqref{eq:xxx}` |
| 图 | 图1, 图2, ... | 如图 5 所示 | `\ref{fig:xxx}` |
| 表 | 表1, 表2, ... | 见表 2 | `\ref{tab:xxx}` |
| 文献 | [1], [2], ... | 根据文献 [3] | `\cite{refxxx}` |
| 节 | 1, 1.1, 1.1.1 | 第 2.1 节 | 自动编号 |

**层次标题编号（🔴 韩中庚规范）**：

- 格式：阿拉伯数字连续编号、小圆点分隔（1、1.1、2.1.1），**末位数字后不加点、加空格**再接标题文字（"1.1 问题分析"✅；"1.1. 问题分析"❌）；
- 同一层次标题**排比**：用词类型相同/相近、语义相关、语气一致（如"问题一的模型""问题二的模型"）；禁止同一层混用名词短语与完整句子；
- 标题简短明确、贴切内容，避免空泛（"模型求解"→"基于遗传算法的模型求解"）。

### 版本文件命名（🔴 禁止 000 式）

- 论文版本文件一律**语义命名**：`main_round1.pdf`（审稿前基线）/ `main_roundN.pdf`（每轮修改后）/ `main_final.pdf`（终版）
- 🔴 禁止 `main_v000.pdf` / `main_v001.pdf` 式纯数字后缀命名（无轮次语义、无法横向对比）；版本追踪以 git round 分支 + `git notes --ref=score` 为准
- 文件名禁止纯数字（如 `000.pdf`、`01.tex`）

### 格式问题修订流程（用户指出问题清单时，🔴 最小修改 + 复检闭环）

用户/审阅给出格式问题清单（如"图题太长/表注贴表罗列路径/章节与表格顺序颠倒/模型评价序号单句"）时，按此流程执行，**不做大改**：

1. **逐条核对定位**：把每条问题映射到具体源文件与位置（图表编号 ↔ `\caption`/表注 ↔ 章节标题），先列出"问题 → 文件:行 → 修改动作"三列清单，再动手；
2. **最小修改**：只改问题处（图题精简、表注搬位/精简、浮动参数调整、序号单句改段落），🔴 禁止借机重写整章或全文重构——大面积 diff 会引入新错误且难以复核；
3. **重新编译**：`latexmk -xelatex -interaction=nonstopmode main.tex`（或项目惯用编译命令），零错误 + 交叉引用零警告才算修复完成；
4. **latex_linter 复检**：委托 latex_linter 子代理按排版清单复扫本次修改涉及的检查项（重点：41 模型评价段落化 / 43 注释精简去重复 / 42 页码居中 / 45 外部过程语言零出现 / 46 图表不远离引用文段 / 21 表注位置 / 44 表格行按数据）；
5. **reviewer 独立复审**：修改产物必须经 reviewer 独立复审（执行-审阅分离），PASS 才交付；FAIL 按 feedback 返修（≤2 次）。
6. **PDF 视觉自查（编译后，具备视觉能力时）**：加载 `mm-pdf-vision`，执行 `python scripts/pdf_render_pages.py main.pdf --out state/reports/pdf-pages/<版本> --dpi 150`，逐页读图核对页序/页码居中/正文从第4页起≤30 页/摘要≤1 页/无目录/图表位置/乱码/身份信息；无视觉能力则生成人工核查请求单并保持门禁 PENDING。

## Anti-Patterns

| # | 反模式 | 后果 | 正确做法 |
|---|--------|------|---------|
| 1 | 摘要不写结果 | 评委抓不住重点 | 摘要必须有核心数值 |
| 2 | 假设无依据 | 评分低 | 每条假设说明理由 |
| 3 | 公式不编号 | 无法交叉引用 | 所有公式连续编号 |
| 4 | 图表无编号 | 论文无法引用 | "图N"连续编号 |
| 5 | 参考文献格式乱 | 扣分 | 统一 GB/T 7714 |
| 6 | `$$...$$` 裸定界写公式 | 间距/编号不可控、易报错 | `equation`/`align` 环境或 `\[...\]` |
| 7 | 正文直接写 `% # _ &` | 特殊字符报错（Missing $ 等） | `\% \# \_ \&` 转义 |
| 8 | `\label` 重复或写在 `\caption` 前 | multiply-defined / 引用指向错误编号 | 标签唯一且紧跟 caption |
| 9 | 表格过宽或字号随意 | Overfull、同页表格大小不一致 | 列宽用相对 `\textwidth`，全文统一 `\small`/`\footnotesize` |
| 10 | 图表插在段落中间（`[H]`） | 文字被截断、漂移 | `[hbt!]`/`[htbp]` 浮动，图表前后空行 |
| 11 | 同类多图连续独立编号 | 版面碎片化、编号膨胀 | 合并为 subfigure 子图 |
| 12 | 图注/表注与正文同字号 | 注释不显著、不规范 | 统一 `\footnotesize`，表注以"注："开头 |
| 13 | `hyperref` 不设色（colorlinks=true 无 citecolor/linkcolor） | 文献引用默认显示为**绿色**，观感差 | 显式 `citecolor=black, linkcolor=black, urlcolor=blue` |
| 14 | 段落以"**黑体关键词+冒号+句子**"开头（如"维度矛盾：…"）或 `\item \textbf{标签}：内容` 列表 | AI 味重、像评审批注不像论文 | 改写为自然段落：把关键词融入句子（"关于决策维度，…"） |
| 15 | 段落前人工编号（(1)(2)…/①②… 手工写在段首） | 与 LaTeX 自动编号冲突、层次混乱 | 用 itemize/enumerate 环境或自然分段，禁止手写段号 |
| 16 | 正文出现评审/对照元语言："与获奖论文一致"、"作者计算"、"与参考结果对比"、"获奖论文参数矛盾" | 论文暴露评审过程、疑似抄袭对照，评阅大忌 | 一律改为与理论/解析基准对照（"与解析公式计算值偏差 <0.1%"），不得点名任何外部论文 |
| 17 | 图表连续排列（表-表/图-表无过渡紧贴） | 结果无叙述、版面碎片化 | 图表之间补 1-2 句结果叙述（先见文字后见图表） |
| 18 | 符号说明含叙述性文字/分组过多/符号重复 | 符号表比正文还复杂 | 只列被引用符号（≤25 个）、分组 ≤4 组、禁止表内叙述 |
| 19 | caption 乱起（空泛标题、含公式符号、表图题位置错） | 评审找不到图表对应内容 | 表题表上方居中、图题图下方居中，格式"图N 对象+内容" |
| 20 | 摘要出现复杂公式或表格 | 评委不读、第一印象差 | 摘要只写方法与结果，公式图表全部放正文 |
| 21 | 万能假设（"数据真实可靠""不考虑其他因素"） | 等于没写、评委视为凑数 | 每条假设对应一处具体模型简化，建模处能找到生效位置 |
| 22 | 公式连排无文字衔接 | 推导断裂、读者跟不上 | 公式之间补过渡文字（"将式 (5) 代入式 (6) 可得"） |
| 23 | 图表插入但正文不显式引用 | 孤立图表、无效内容 | 正文必须"由图 N 可知/见表 N"显式引用每张图表 |
| 24 | 灵敏度分析无数值（只写"稳定性良好"） | 评委视为空话 | 至少扰动一个关键参数并给出扰动后数值结果与结论变化 |
| 25 | 参考文献信息不全/来源不明裸链接充数 | 格式扣分、无法核验 | GB/T 7714 完整信息 + 可核验 DOI/URL；正文引用与文献表一一对应 |
| 26 | 层次标题编号错误（末位加点"1.1."、同层混用句式） | 层次混乱、不专业 | 编号末位不加点、后加空格；同一层次标题排比 |
| 27 | 模型评价不写缺点（回避自评或只夸优点） | 不满足官方评阅要求 | 必须写优缺点 + 改进方向，缺点回指模型局限 |
| 28 | 全文出现身份/学校信息，或附录缺完整可运行源码 | **可能取消评奖资格** | 全文匿名；附录含支撑材料文件列表 + 全部完整源码 |
| 29 | 模型评价/改进方向写成"序号+一句话"罗列（"1. 局部平面近似的局限：……"） | AI 味极重、不像论文论述 | 每条写成完整段落（论点+依据+影响 2-4 句），段落自然衔接 |
| 30 | 图题/表注罗列内部文件路径与工程黑话（`Code/output/…`、`p4_result.txt`、"canonical 生产方案"） | 暴露工程过程、评委无法核验、不学术 | 数据来源只写"本文模型计算/文献[n]/数据集名"；工程命名改学术表述（本文方案/对比方案） |
| 31 | 图题冗长（塞入条数、疏密说明、数据来源、绘制方法、附件指引、流程箭头复述） | 题注不像题注、排版拥挤 | 图题一行以内"图N 对象+内容"；来源与说明移注释行或正文 |
| 32 | 表注/图注写成两端对齐长段，或紧贴表体/图题被视觉吞并，或写在 `\end{table}` 后滞留源码处与浮动表格分离 | 注与表图边界不清/注文错位 | 注放浮动环境内 tabular 之后，左对齐 footnotesize 一行、留 3-6pt 间距 |
| 33 | 图表漂移到所属章节标题之前（如"表1 符号表"出现在"符号说明"标题前） | 章节与表格顺序颠倒、结构错乱 | 编译后核对：图表位于所属章节标题后 + 首次引用后；必要时 `\FloatBarrier` 或源码下移 |
| 34 | 正文超过 20 页 / 问题重述复制题目原文 | 超页扣分 / 评阅印象差 | 严控页数；用自己的话重述 |
| 35 | 每张表/图都写长串数据来源与复现说明（"完整代码见附件、按式(x)复核、逐条明细见独立附件、不在本文重复"） | 表注/图注机械、重复、啰嗦；评委注意力被稀释 | 同源数据在首次或正文统一说明一次；注释只写该表/图未体现且必要的信息；删除全部内务/复现话术 |
| 36 | 表格行数不按实际数据组织（为凑对齐补空行/虚行/机械同列数） | 表格失真、不专业 | 每行对应一个真实数据实体（测线/阈值/方案等），行数由数据决定 |
| 37 | 外部/内部工作语言进入论文："经过N轮迭代""与上一版本相比""修改前后对比"及内部对比表 | 暴露内部过程、疑似非正式产出；评审大忌 | 论文只呈现最终模型与结果；内部迭代/版本/对比留在 state/reports、state/reviews 与 git 记录 |
| 38 | 页码未在页脚居中（或摘要页页码缺失） | 格式不合规 | `\fancyfoot[C]{\thepage}` 页脚中部阿拉伯数字；摘要页起编号，承诺书/编号页不编号；编译后逐页核对 |

## 同步兼容模式：Markdown → LaTeX

当项目已有 Markdown 论文时，先保留 Markdown 原始快照，再转换到 `ReportPaper/LaTeX/`。LaTeX 是唯一可维护文档源；PDF 只能通过 LaTeX 编译生成。转换前必须确认代码独立审阅和数据质量门禁已通过；转换后必须运行 `latexmk -xelatex -interaction=nonstopmode main.tex` 并检查交叉引用、图表路径和参考文献。

## Pro 知识库融合（v1.7.0）：创新点设计与论文证据表达

> 融合自 math-modeling-skill-pro（作者授权）：六类可迁移创新模式、论文章节设计与摘要写法、交付前一致性审计。

### 资产位置
- `skills/mm-latex-writing/assets/pro/innovation-patterns.md`：创新机会诊断、六类创新（结构/组合/指标/约束/数据/算法）、候选筛选、证据阶梯、伪创新否决条件
- `skills/mm-latex-writing/assets/pro/paper-writing.md`：论文结构与证据表达（主张—证据—限制三元组、章节设计、摘要四层结构、公式图表规范、一致性审计）
- `skills/mm-latex-writing/assets/pro/templates/paper-outline.md`、`abstract-template.md`：目录与摘要模板

### 使用时机
N7 论文写作：①每子问「主张—证据—限制」三元组 → ②章节按「问题→模型→证据→结论」组织 → ③摘要四层（背景/目标、方法+选择理由、可核验结果、结论/价值）→ ④创新写成「缺陷—改动—证据—代价—边界」→ ⑤交付前一致性审计逐项核对（任务/数学/结果/复现合规）。

### 与既有流程的关系
- 本技能已有的国赛 10 节结构/LaTeX 规范为骨架；Pro 资产补充证据强度纪律：禁止无指标的「效果很好/较高精度」，禁止「首次/显著领先/普遍适用」等无法证明的表述。
- 创新点必须可消融、可解释、可验证；仅换模型名称/深网络/多优化器属于伪创新。
- 摘要禁止填虚构结果，未运行前使用 `{待计算}`/`{待验证}` 占位（与既有去 AI 化、latex-linter 门禁衔接）。

### 回退
与既有模板冲突时以 Pro 证据纪律为准；局限至少写清「哪个假设可能偏离、偏离方向、可验证方式、部署前如何重校准」。
