## 模型分类速查表

### 一、优化类模型

| 模型 | 适用题型 | 输入要求 | Python 库 | 典型 CUMCM 题目 |
|------|---------|---------|----------|----------------|
| **线性规划 (LP)** | 资源分配、生产调度 | 目标函数系数、约束矩阵、约束向量 | `scipy.optimize.linprog`, `pulp`, `ortools` | 企业生产计划 |
| **整数规划 (IP)** | 排班、选址、分配 | 同 LP + 整数约束 | `pulp`, `ortools` | 仓库选址、人员排班 |
| **多目标规划** | 多目标权衡 | 多个目标函数、约束 | `scipy.optimize`, `pymoo` | 供应链多目标优化 |
| **动态规划 (DP)** | 阶段决策、最优路径 | 阶段数、状态转移方程、收益函数 | 自定义实现 | 最短路径、资源分配 |
| **非线性规划 (NLP)** | 非线性目标/约束 | 非线性目标函数、约束 | `scipy.optimize.minimize` | 工程优化设计 |
| **遗传算法 (GA)** | NP-hard 问题 | 适应度函数、编码方式 | `deap`, `pymoo` | 复杂组合优化 |
| **模拟退火 (SA)** | 大规模组合优化 | 能量函数、邻域定义 | `simanneal` | TSP、调度问题 |
| **粒子群优化 (PSO)** | 连续/离散优化 | 适应度函数 | `pyswarm` | 参数优化 |

### 二、预测类模型

| 模型 | 适用题型 | 输入要求 | Python 库 | 典型 CUMCM 题目 |
|------|---------|---------|----------|----------------|
| **线性回归** | 线性趋势预测 | 自变量、因变量 | `sklearn.linear_model`, `statsmodels` | 销量预测 |
| **多元回归** | 多因素预测 | 多个自变量、因变量 | `sklearn`, `statsmodels` | 影响因素分析 |
| **ARIMA** | 时间序列预测 | 时间序列数据 | `statsmodels.tsa` | 股票/气象预测 |
| **灰色预测 GM(1,1)** | 小样本、贫信息 | 少量时间序列数据 | `gm` (自实现) | 人口预测、能源预测 |
| **BP 神经网络** | 非线性映射 | 特征矩阵、标签 | `sklearn.neural_network`, `torch` | 信用评估 |
| **LSTM** | 长序列时序预测 | 长时间序列 | `torch`, `keras` | 股价预测、气象预测 |
| **随机森林** | 分类/回归 | 特征矩阵、标签 | `sklearn.ensemble` | 风险评估 |
| **XGBoost** | 结构化数据预测 | 特征矩阵、标签 | `xgboost` | 竞赛预测类题目 |
| **Prophet** | 含节假日的时间序列 | 日期 + 值 | `prophet` | 销量/流量预测 |

### 三、评价类模型

| 模型 | 适用题型 | 输入要求 | Python 库 | 典型 CUMCM 题目 |
|------|---------|---------|----------|----------------|
| **层次分析法 (AHP)** | 多准则决策 | 判断矩阵 | `pydecision` | 方案优选、供应商评价 |
| **TOPSIS** | 方案排序 | 决策矩阵（标准化后） | `scikit-criteria` | 评价排序 |
| **熵权法** | 客观赋权 | 指标矩阵 | 自实现 | 指标权重确定 |
| **模糊综合评价** | 模糊边界评价 | 评价因素集、评语集 | `fuzzy` (自实现) | 水质评价、安全评估 |
| **灰色关联分析** | 小样本关联度 | 参考序列、比较序列 | 自实现 | 影响因素排序 |
| **主成分分析 (PCA)** | 降维/综合评价 | 指标矩阵 | `sklearn.decomposition` | 综合评分 |
| **CRITIC 权重法** | 客观赋权 | 指标矩阵 | 自实现 | 权重确定 |

### 四、统计类模型

| 模型 | 适用题型 | 输入要求 | Python 库 | 典型 CUMCM 题目 |
|------|---------|---------|----------|----------------|

| **方差分析 (ANOVA)** | 多组差异比较 | 多组样本数据 | `scipy.stats`, `statsmodels` | 实验效果比较 |

| **二部图匹配** | 匹配分配 | 二部图 | `networkx` | 任务分配 |

## 模型选型决策树

```
题目拿到后：
│
├─ 优化类问题（求最大/最小）？
│   ├─ 线性？ → 线性规划
│   ├─ 整数约束？ → 整数规划
│   ├─ 多目标？ → 多目标规划
│   ├─ 非线性？ → 非线性规划 / GA / PSO
│   └─ NP-hard？ → 遗传算法 / 模拟退火
│
├─ 预测类问题（预测未来值）？
│   ├─ 有大量数据？ → 回归 / 神经网络 / XGBoost
│   ├─ 时间序列？ → ARIMA / LSTM / Prophet
│   ├─ 小样本？ → 灰色预测 GM(1,1)
│   └─ 非线性？ → BP 神经网络 / 随机森林
│
├─ 评价类问题（排序打分）？
│   ├─ 有专家判断？ → AHP + TOPSIS
│   ├─ 纯客观数据？ → 熵权法 / CRITIC
│   ├─ 模糊边界？ → 模糊综合评价
│   └─ 降维？ → PCA
│
├─ 图论类问题（网络/路径）？
│   ├─ 最短路径？ → Dijkstra
│   ├─ 连通性？ → MST
│   ├─ 流量？ → 网络流
│   └─ 巡回？ → TSP
│
├─ 动态演化问题？
│   ├─ 连续时间？ → ODE/PDE
│   ├─ 离散时间？ → 元胞自动机
│   └─ 随机？ → Monte Carlo
│
└─ 统计推断问题？
    ├─ 差异检验？ → 假设检验 / ANOVA
    ├─ 关联分析？ → 相关分析
    └─ 分类判别？ → Logistic / 判别分析
```

## 模型组合策略

国赛常见模型组合：

| 组合 | 场景 | 说明 |
|------|------|------|
| AHP + TOPSIS | 评价排序 | AHP 确定权重，TOPSIS 排序 |
| 熵权法 + TOPSIS | 客观评价 | 熵权法定权，TOPSIS 排序 |
| ARIMA + 神经网络 | 组合预测 | 线性+非线性组合 |
| 灰色预测 + 马尔可夫链 | 小样本预测 | 灰色趋势 + 马尔可夫修正 |
| ODE + Monte Carlo | 随机动态系统 | 确定性模型 + 随机扰动 |
| 线性规划 + 整数规划 | 混合优化 | 连续松弛 + 整数化 |

## Pro 知识库融合（v1.7.0）：模型选择三方案与模型卡

> 融合自 math-modeling-skill-pro（作者授权）：139 篇优秀论文的选型决策模式。本技能速查表负责「有哪些模型」，Pro 资产负责「如何可辩护地选」。

### 资产位置
- `skills/mm-model-library/assets/pro/model-selection.md`：选择流程（模型无关规格→基线→候选族→硬筛→软评分→决策记录）、三方案设计（A 经典稳妥/B 竞赛高分/C 创新探索）、模型族决策表
- `skills/mm-model-library/assets/pro/model-library.md`：模型卡「用/慎禁/验/替升」候选生成器（预测/评价/优化/分类/聚类/图论/机理/仿真）
- `skills/mm-model-library/assets/pro/model-combinations.md`：组合准入规则、12 个可复用组合模式、反模式与拆除规则
- `skills/mm-model-library/assets/pro/templates/model-design.md`：模型设计模板（护照/三方案/数学定义/可辨识性/验收标准）

### 使用时机
N3 建模输出前必须完成：①写模型无关规格 → ②基线 → ③候选族（不同归纳偏置）→ ④硬筛（数据量/时间可用性/依赖结构/可辨识性/可行性/目标一致/评价语义/可解释/预算/验证能力）→ ⑤三方案 A/B/C 对比 → ⑥选择记录（候选/淘汰原因/验证/回退）。

### 关键决策规则（违反即视为弱结论）
- 三方案必须是三个可辩护层级，不是三个模型名字。
- 元启发式不得先于优化模型形式化与精确/凸求解器检查。
- AHP+熵权+CRITIC+PCA+TOPSIS 不得机械叠加，除非各自职责独立且冗余已检验。
- 每个复杂模型必须回答「新增复杂度解决什么可测问题」；失败时明确回退方案。
- 模型频次只能用于检索，不能证明优越性。

### 回退
与既有速查表冲突时以 Pro 决策规则为准（速查表是菜单，Pro 是候选生成器+选型纪律）；无法满足硬筛的模型直接淘汰。
