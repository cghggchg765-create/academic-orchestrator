**核心机制**：`round-score`（N4/N5/N7）与 `node-review`（N1/N3 PASS）机器校验 `state/reports/mcp-calls.jsonl` 或 `state/cases/index.json` 检索留痕——**每轮重新检索、禁止纯内生**（`--allow-missing-mcp` 显式豁免）；`round-decide` 未达标强制 `--reason` 失败原因分析；`search-evidence <Nx>` 汇总知识卡片/台账/留痕随派发分发给 Agent；`round-score` 每轮自动采集 `rounds[n].knowledge_cards`（`{节点}_r{轮}_*.md` 命名约定）实现**轮次→卡片传递**；**Deep Research 链**（research_architect→literature→researcher→synthesis→report_compiler）按需介入每轮迭代并 `dr-note` 留痕（`dr-list` 查询，N8 可核对"每轮有据介入"）。
> 完整协作闭环与深度研究嵌入规格见 **`docs/optimization/agent-collaboration-loop.md`**（9 阶段协作闭环表 / Deep Research 嵌入点清单 / 迭代环融合方案，统一 SSOT）；组件引用全景与重叠决策见 **`docs/optimization/组件盘点与合并规划.md`**。

## 6. 状态与产物落点闭环

```
state/decision_log.json（唯一事实源，orchestrator 单写）↔ 9 节点首页 ↔ registry.json ↔ search_sources.json ↔ cases/
  ├─ 产物落点：ProblemInfo/ → Data/ → ModelDocs/ → Code/output/ → ResultFigures/ → ReportPaper/LaTeX/ → SubmissionPackage/
  ├─ 检索证据：state/reports/{mcp-calls.jsonl, mcp-cards/, references-ledger.md}（search-evidence 派发）
  ├─ Deep Research 留痕：state/reports/dr-interventions.jsonl + rounds[n].deep_research（dr-note/dr-list）
  ├─ 迭代轮次卡片：rounds[n].knowledge_cards（{节点}_r{轮}_*.md，评分自动采集；N8 校验"迭代有新检索"）
  ├─ 迭代证据：state/reports/{review,decision,result} + LogRecord/version-update.md + git notes --ref=score
  └─ N8 终检：五节点必调留痕 + 每轮新检索（knowledge_cards）+ 知识卡片 + 台账 + 去AI化报告 全闭环 → A3 → 提交清单
```
